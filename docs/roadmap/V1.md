# Roadmap V1 - Search Box Core

> Historical release record. The current application is Quarkus on Java 25; the Spring Boot starter was removed. See [current phase audit](../platform/phase-acceptance.md).

## Scope

V1 focuses only on Search Box Intelligence.

## Included

- Spring Boot service
- REST API
- Step-based pipeline engine
- Result-based execution context
- Language detection
- Intent detection
- Threat analysis
- Query rewrite mock
- Semantic validation mock
- Policy evaluation
- Confidence calculation
- Decision engine
- Pipeline trace
- Unit tests
- API integration tests
- GitHub Actions CI
- Docker support

## Excluded

- Forms
- Payments
- Checkout flows
- AI Prompt Gateway
- API Gateway
- Database
- Product catalog
