# Roadmap V3 - Search Intelligence Expansion

> **Historical record.** It describes the repository at the time it was written. Modules and connectors it mentions may have been removed since: QB-287 removed the Elasticsearch, PostgreSQL, MongoDB and Shopify connector modules and `examples/` (ADR 0058). For the current state, start at [docs/README.md](../README.md).

## Goal

Extend the search intelligence platform beyond basic query analysis.

## Planned

- Search Analytics
- Query Suggestions
- Typo Correction
- Synonym Engine
- Spell Checking
- User Feedback Loop
- Rewrite Ranking
- A/B Rewrite Evaluation
- Metrics Dashboard
- Search Quality Evaluation

## Final V3 Closure

V3 is considered functionally complete.

Completed:
- Search Provider SPI
- InMemory provider
- OpenSearch provider
- OpenSearch client
- Query factory
- Response mapper
- Backend-aware provider resolution
- Structured search response
- End-to-end API execution with OpenSearch
- Unit and integration-style tests

Known limitation:
- End-to-end latency is high because AI pipeline steps currently call Ollama sequentially.

Deferred to V4:
- Parallel AI pipeline
- Single-call AI analysis
- Result caching
- Better runtime profiles for local/dev/test
