# V6 — Public Product Hardening

## Goal

Harden QwenBridge as a public product by freezing API/SSE contracts, defining provider reliability semantics, verifying real retrieval behavior, and preparing production launch evidence.

## Scope

1. API contract, validation, and failure semantics
2. SSE failure envelope and lifecycle hardening
3. AI provider reliability and bounded retry policy
4. Ollama-only launch routing with no automatic failover
5. OpenSearch vector retrieval contract
6. Portable hybrid retrieval using `bool.should`
7. Real BGE-M3 embedding-backed retrieval verification
8. Production runtime and security hardening
9. Documentation and OSS launch readiness
10. Architecture quality and release gates

## Completed Evidence

- Public REST failure contracts are covered by tests.
- SSE failure semantics and terminal lifecycle are covered by tests.
- Public REST and SSE contracts are documented.
- AI provider timeout, retry, and no-failover policy are documented.
- OpenSearch vector and hybrid query contracts are implemented.
- Real Ollama `/api/embed` mapping is verified.
- Real OpenSearch hybrid retrieval integration test exists.
- Retrieval ranking and reranking policy are documented.

## Release Gate

V6 is releasable only when:

- all unit tests pass
- optional provider integration tests are documented
- public API compatibility rules are frozen
- Docker runtime verification passes
- no known critical security gaps remain
