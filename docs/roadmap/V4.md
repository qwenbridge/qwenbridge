# Roadmap V4 - Secure Fast AI Pipeline

## Goal

Reduce search analysis latency and harden the search input pipeline against malicious, abusive, obfuscated, or unsafe input.

## In Scope

- Single AI Analysis Call
- AI Response Cache
- Modular Threat Detection Framework
- Input Normalization Framework
- SQL Injection Detection
- XSS Detection
- Prompt Injection Detection
- Command Injection Detection
- Path Traversal Detection
- Template Injection Detection
- NoSQL Injection Detection
- LDAP Injection Detection
- SSRF Detection
- Secret Leakage Detection
- Jailbreak Detection
- Unicode and Encoding Obfuscation Detection
- Pluggable Threat Detectors
- Threat Scoring
- Threat Decision Engine
- Runtime Performance Profiling
- Pipeline ordering cleanup
- Unit and integration tests

## Out of Scope

- Intelligent Forms
- Payments
- Checkout flows
- User accounts
- Production distributed cache
- External hosted AI providers
- Full WAF replacement

## Success Criteria

- End-to-end analysis uses one AI call instead of multiple sequential calls.
- Repeated queries can be served from cache.
- Threat detection is modular and independently testable.
- Every threat detector has dedicated positive and negative tests.
- API response includes runtime profiling.
- V3 OpenSearch execution remains backward compatible.
