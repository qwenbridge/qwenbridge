# QwenBridge TypeScript SDK

Official TypeScript SDK for QwenBridge.

## Status

This package is under active development as part of the QwenBridge V9 developer platform release.

## Requirements

- Node.js 20 or newer
- A reachable QwenBridge API instance

## Local development

Run these commands from this package directory:

    npm install
    npm run build
    npm test
